Command Cheat Sheet

Master the Terminal Workflow

Intuitive commands designed around your everyday study needs. URLs or IDs are both supported.

uit login

Interactive SSO login via browser. Supports --legacy for the classic Moodle portal.

uit courses

List enrolled courses for the current semester with course IDs and progress.

uit contents <course-id>

Inspect course outline, weekly lecture slides, announcements, and files.

uit assignments

List upcoming deadlines, overdue items, and submission status across all subjects.

uit grades <course-id>

Display gradebook breakdown including quizzes, midterms, labs, and final marks.

uit studio

Launch the native desktop interface with PDF previews and the Codex AI Copilot.

Got Questions?

Frequently Asked Questions

Does UIT CLI store my university password? +
No. Interactive login opens official UIT Single Sign-On (SSO) in your browser. The CLI receives an authenticated session token, which is saved locally to ~/.uit/sessions.json with strict 0600 Unix file permissions. Your raw password is never intercepted or saved.
Do I need OpenAI Codex to use UIT Studio? +
No. All core Moodle features (browsing courses, inspecting assignments, viewing grades, and offline downloads) work completely standalone. Codex CLI is only required if you want to enable the AI Study Copilot agent chat.
Can I integrate UIT CLI into scripts and other tools? +
Yes! Every command supports the --json flag to output clean, structured JSON payloads directly to standard out, making it trivial to pipe into jq, cron jobs, or notification scripts.
How do I update to the latest version? +
Run npm update -g uit-cli uit-studio or re-run the official installer script. You can also check the GitHub Releases page for new binary builds.
