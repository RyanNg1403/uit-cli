🏛️ Giá trị thực tiễn

Giải pháp toàn diện cho sinh viên UIT

Được xây dựng từ nhu cầu thực tế của sinh viên Công nghệ Thông tin ĐHQG-HCM.

⚡

Tốc độ Terminal tuyệt đỉnh

Không cần mở trình duyệt và đợi Moodle tải từng trang. Tra cứu deadline, xem thông báo mới, điểm số chỉ trong nửa giây ngay tại command line.

🖥️

UIT Studio Native Desktop

Ứng dụng desktop đa nền tảng tối ưu cho macOS, Linux và Windows. Tích hợp trình đọc PDF slide bài giảng, phân chia học kỳ thông minh và Dark Mode dịu mắt.

🤖

Codex AI Trợ lý Học tập

Tận dụng OpenAI Codex để giải đáp thắc mắc dựa trên chính slide và bài tập của giảng viên UIT. Giúp bạn tóm tắt bài giảng, gợi ý giải thuật và chuẩn bị thi cuối kỳ.

🔐

Xác thực UIT SSO Chuẩn mực

Đăng nhập một lần qua cổng UIT Central SSO. Tuyệt đối không lưu mật khẩu ở dạng plaintext. Token phiên được lưu phân quyền an toàn 0600 dùng chung cho cả CLI và Studio.

📁

Học tập Offline bất cứ lúc nào

Tự động tải và đồng bộ toàn bộ tài nguyên môn học vào cấu trúc thư mục rõ ràng trên máy tính cá nhân. Thoải mái học tập ôn thi ngay cả khi mạng trường bị bảo trì.

🔌

Model Context Protocol (MCP)

Tích hợp sẵn MCP Server chuẩn mở, cho phép Claude Code, Codex CLI hoặc Cursor gọi trực tiếp dữ liệu bài tập và tiến độ Moodle vào phiên lập trình của bạn.

Cài đặt dễ dàng trong 1 phút

Hoạt động trơn tru trên macOS, Linux và Windows.

Apple Silicon / Intel
🍎

macOS

Cài đặt CLI nhanh qua script tự động kiểm tra checksum, hoặc tải bản ứng dụng Desktop DMG.

curl -fsSL https://raw.githubusercontent.com/RyanNg1403/uit-cli/main/scripts/install.sh | sh
Tải file .DMG cho macOS
AppImage / Binary
🐧

Linux

Phù hợp cho các bạn sinh viên dùng Ubuntu, Arch, Fedora hoặc môi trường WSL2.

curl -fsSL https://raw.githubusercontent.com/RyanNg1403/uit-cli/main/scripts/install.sh | sh -s -- --studio
Tải AppImage cho Linux
PowerShell / Installer
🪟

Windows

Yêu cầu Node.js 20.19+. Cài đặt toàn cục qua npm hoặc tải bộ cài Windows Setup.

npm install -g uit-cli uit-studio
Tải bản cài đặt Windows (.exe)
❓ Giải đáp thắc mắc

Câu hỏi thường gặp

Tuyệt đối không. Lệnh uit login sẽ mở trang đăng nhập chính thức của UIT Single Sign-On (CAS/SSO) trên trình duyệt web của bạn. Ứng dụng chỉ nhận session token đã xác thực từ trường và lưu cục bộ tại ~/.uit/sessions.json với phân quyền bảo vệ nghiêm ngặt 0600 (chỉ tài khoản người dùng máy bạn đọc được).
Không bắt buộc. Tất cả tính năng tra cứu môn học, danh sách bài tập, xem điểm số, tải bài giảng và giao diện Desktop Studio đều hoạt động hoàn toàn độc lập mà không cần Codex. Bạn chỉ cần cài đặt Codex CLI nếu muốn sử dụng tính năng Trợ lý AI trao đổi bài tập.
Có. Bạn chỉ cần chạy lệnh uit login --legacy để đăng nhập vào cổng Moodle truyền thống bằng Mã số sinh viên và Mật khẩu.
Rất dễ dàng! Tất cả các lệnh của UIT CLI đều hỗ trợ flag --json. Bạn có thể kết hợp với jq, cron hoặc viết script Python/Node.js để tự động gửi thông báo bài tập sắp đến hạn.
